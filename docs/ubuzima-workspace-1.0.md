# Ubuzima+ Workspace 1.0

## Product

**Commercial name:** Ubuzima+ Workspace

Ubuzima+ Workspace is the full native business application for Windows, macOS, Android tablets, and iPad. It mirrors the complete capability of the Ubuzima+ web application through native/adaptive interfaces rather than embedding the website in a WebView.

## Supported platforms

- Windows
- macOS
- Android tablet
- iPad

## Experience contract

Ubuzima+ Workspace uses a full business workspace layout optimized for keyboard, mouse, touch, larger screens, data tables, approvals, reports, printing, file actions, and administrative workflows.

The Android/iPhone phone application remains a separate mobile-first experience for fast operational workflows.

## Shared platform contract

Workspace and Phone share the same Ubuzima+ backend, authentication rules, permissions, API contracts, business models, branding, and security controls. Presentation shells remain separate.

## Functional parity target

The Workspace release will cover the same permitted functionality as the production web application, including the applicable areas of:

- 360 Business View
- POS & Sales
- Inventory
- Procurement
- Finance
- HR and workforce functions
- Reports and statements
- Approvals and maker/checker flows
- Administration and settings
- User, role, branch, and permission controls

Parity is verified module-by-module against the production web application before commercial release.

## Commercial release identity

- Product version: 1.0.0
- App name shown to customers: Ubuzima+ Workspace
- Application identifier target: com.ubuzimaplus.workspace
- Production backend: https://ubuzimaplus.com

## Release rule

No Workspace build replaces or modifies the production web application. Every platform is distributed as a separate signed application and must pass platform-specific UAT before publication in the Ubuzima+ App Center.
